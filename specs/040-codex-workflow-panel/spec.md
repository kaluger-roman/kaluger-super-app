# Панель рабочего процесса в Codex

## Запрос

Пользователь хочет видеть issues и рабочие сессии непосредственно в Codex,
с сопоставимыми действиями существующего расширения VS Code. Всё работает
локально на Mac с текущим GitHub-репозиторием.

## Требования

- Локальный устанавливаемый плагин с глобальной панелью и вкладкой чата.
- Открытые issues: приоритет 0–100, поиск, неоценённые, ссылка на GitHub,
  связь с существующей сессией и выбор обычного/bug-fix/feature workflow.
- Сессии: доступные live-статусы, история, лента операций, сабагенты и PR.
- Обновление данных с явными ошибками; история не выдаётся за live.
- Действие пользователя подготавливает запрос выбранного workflow через
  поддерживаемый host API; issue-текст не исполняется как shell-код.
- Данные и процессы остаются локальными; нет SSH, production или новых
  хранилищ GitHub credentials.

## Ограничение платформы

Shared Codex daemon предоставляет live CLI threads через Unix WebSocket.
Текущий desktop app-server использует приватный stdio и не предоставляет
публичный socket для подключения панели. Его история доступна, live-статус
нельзя обещать или подменять наблюдением за другим сервером.

## Критерии приёмки

Установленный плагин обнаруживает инструменты, возвращает реальные issues,
открывает интерактивную панель в Codex и позволяет выбрать workflow. Поведение
без host capabilities и при недоступном daemon отображается явно. Проверены
автоматические регрессии, упаковка и актуальный CI PR #205.
