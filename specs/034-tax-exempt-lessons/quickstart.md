# Quickstart: 034-tax-exempt-lessons

Как поднять фичу локально, применить миграцию и вручную проверить
сценарии спеки.

## 1. Окружение

Ветка `034-tax-exempt-lessons` (worktree
`.claude/worktrees/uroki-bez-naloga-tmp`). В свежем worktree:

```bash
ls -l frontend/node_modules backend/node_modules   # симлинки из основного чекаута
ls backend/.env backend/.env.test                  # скопированы из основного чекаута
```

## 2. Миграция

```bash
cd backend
npm run db:migrate        # имя миграции: add_lesson_tax_exempt
npm run db:generate
npm run db:migrate:test
```

Проверка бэкфилла (FR-001, SC-001):

```sql
SELECT COUNT(*) FROM lessons WHERE "isTaxExempt" IS DISTINCT FROM false;  -- 0
```

## 3. Запуск

```bash
cd backend && npm run dev     # http://localhost:3001
cd frontend && npm start      # http://localhost:3000
```

Профиль → включить «Учитывать налог», задать период ставки 6%
с начала года.

## 4. Ручная проверка по историям

### US1: признак в попапе и в форме

1. Уроки → открыть попап любого старого урока: переключатель
   «Не облагается налогом» выключен.
2. Включить: тост «Урок обновлен», у урока в списке появился значок
   «0% без налога». Закрыть и снова открыть попап: переключатель включён.
3. Выключить: значок пропал.
4. DevTools → Network → Offline → переключить: тост с ошибкой,
   переключатель в прежнем положении. Вернуть Online.
5. Создать урок: в форме переключатель «Не облагается налогом»
   (оформлен как «Оплачено» / «ДЗ», не чекбокс), включить, сохранить:
   у урока значок.
6. Отредактировать урок, переключить признак, нажать «Отмена»: признак
   не изменился. Переключить и сохранить: изменился.
7. Создать регулярное занятие с включённым признаком: значок у всех
   уроков серии. В попапе одного урока серии выключить признак: у
   остальных уроков серии он остался (FR-008).
8. Отменить прошедший урок, затем включить у него признак: статус
   остался «Отменён» (research R5).
9. Профиль → выключить учёт налога: нет ни переключателя в попапе,
   ни поля в форме, ни значков. Включить снова: признаки на месте.
10. Кабинет ученика помеченного урока: ни признака, ни значка.

### US2: налог в статистике

1. Два урока в текущем месяце по 1000 ₽ и 2000 ₽, оба оплачены,
   второй помечен.
2. Статистика: «Налоги (6%)» = 60 ₽; «Заработок» и «Поступления за
   период» = 3000 ₽. Info-иконка рядом с подписью, в тултипе
   «6% × 1 000 ₽ = 60 ₽» и «Не облагается налогом: 2 000 ₽».
3. Снять признак, вернуться на статистику: 180 ₽, строки про
   необлагаемые оплаты нет, иконки при одной ставке нет (как до фичи).
4. Пометить все оплаты периода: налог 0 ₽, подпись «Налоги (6%)»,
   в тултипе строка «Не облагается налогом».
5. Урок, оплаченный в прошлом месяце: пометить и выбрать прошлый месяц
   в фильтре — налог уменьшился ровно на налог по уроку.
6. Отметить оплаченным необлагаемый урок с комиссией: «Списано в счёт
   комиссий» такое же, как без признака.
7. Тултип налога: строки ставок и новая строка одного цвета; цвет
   первой строки совпадает с `main` (research R17).

### US3: значок в карточке и в календаре

1. Список уроков: значок рядом со стоимостью только у помеченных
   уроков, у остальных нет ни значка, ни пустого места.
2. Наведение, фокус с клавиатуры (Tab), тап на мобильной ширине:
   подсказка «Не облагается налогом. Доход по уроку не учитывается
   в сумме налога». Тап по значку не открывает попап урока.
3. Урок с признаком, комиссией и отметкой регулярного занятия на 375px:
   все пометки читаемы, вёрстка не ломается.
4. Вид «Расписание»: в ячейке урока значок «0%» без текста, с той же
   подсказкой.
