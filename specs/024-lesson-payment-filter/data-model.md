# Data Model: Фильтрация уроков по дате оплаты

## Существующие сущности (без изменений)

### Lesson (Урок)

Поле `paymentDate` уже существует в модели. Миграция БД не требуется.

| Поле | Тип | Описание | Релевантность для фильтра |
|------|-----|----------|---------------------------|
| id | String (cuid) | Уникальный ID | - |
| paymentDate | DateTime? | Дата оплаты урока | Основное поле фильтрации |
| isPaid | Boolean | Оплачен ли урок | Взаимоисключающий фильтр |
| price | Float? | Цена урока | Используется в `onlyUnpaid` |
| startTime | DateTime | Время начала урока | Существующая фильтрация |
| status | LessonStatus | Статус урока | Существующая фильтрация |
| studentId | String | ID ученика | Существующая фильтрация |

## Новые клиентские сущности

### PaymentDateFilter (состояние фильтра на фронте)

| Поле | Тип | Описание |
|------|-----|----------|
| paymentDateFrom | Date \| null | Начальная дата диапазона оплаты |
| paymentDateTo | Date \| null | Конечная дата диапазона оплаты |
| paymentDatePreset | PaymentDatePreset | Выбранный предустановленный период |

### PaymentDatePreset (enum)

| Значение | Описание |
|----------|----------|
| `null` | Предустановленный период не выбран |
| `"currentMonth"` | Текущий месяц (1-е число — последний день) |
| `"lastMonth"` | Прошлый месяц |
| `"currentWeek"` | Текущая неделя (понедельник — воскресенье) |

## Валидация

| Правило | Описание |
|---------|----------|
| `paymentDateFrom <= paymentDateTo` | Если оба заданы, начальная дата не позже конечной |
| Хотя бы одна дата | Фильтр активен только если хотя бы одна дата задана |
| Взаимоисключение с `onlyUnpaid` | При `onlyUnpaid=true` даты оплаты игнорируются |

## Связи между фильтрами

```
onlyUnpaid = true  →  paymentDateFrom = null, paymentDateTo = null, paymentDatePreset = null
paymentDateFrom/To заданы  →  фильтрует только уроки с NOT NULL paymentDate
```
