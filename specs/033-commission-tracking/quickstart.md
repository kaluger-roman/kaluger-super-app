# Quickstart: 033-commission-tracking

Как поднять фичу локально, применить миграцию и вручную проверить
основные сценарии спеки.

## 1. Окружение

Ветка `033-commission-tracking` (worktree). В свежем worktree:

```bash
# node_modules симлинками из основного чекаута, backend/.env и .env.test на месте
ls -l frontend/node_modules backend/node_modules
ls backend/.env backend/.env.test
```

## 2. Миграция

```bash
cd backend
npm run db:migrate        # prisma migrate dev — создаст и применит миграцию
npm run db:generate       # перегенерировать клиент (типы Student.commissionAmount)
npm run db:migrate:test   # та же миграция на тестовой БД (.env.test)
```

Проверка бэкфилла (FR-003 / SC-002): у **всех** ранее заведённых учеников
`commissionAmount` должен стать `0`, а не `NULL`.

```bash
npm run db:studio   # или psql: SELECT COUNT(*) FROM students WHERE "commissionAmount" <> 0;
```

## 3. Запуск

```bash
cd backend && npm run dev     # http://localhost:3001
cd frontend && npm start      # http://localhost:3000
```

## 4. Ручная проверка по историям

### US1 — поле «Комиссия» у ученика

1. Ученики → создать ученика, оставить «Комиссия» пустой → сохранить.
   Переоткрыть: комиссия `0`, никаких блоков про комиссию в карточке.
2. Редактировать → «Комиссия» `3000` → сохранить → переоткрыть форму:
   в поле `3000`.
3. Ввести `-100` → поле краснеет с текстом «Комиссия не может быть
   отрицательной», кнопка сохранения **не сохраняет** (тост с ошибкой).
4. Открыть ученика, заведённого до фичи: карточка выглядит как раньше,
   ни одной пометки про комиссию.

### US2 — пометки на уроках

1. Ученику с комиссией `2500 ₽` провести три урока по `1000 ₽`,
   каждый перевести в «Завершён» + «Оплачен».
2. Список уроков: у первого и второго — `(1 000 ₽)` со сплошным
   значком рукопожатия, у третьего — `(500 ₽)`, у четвёртого и далее —
   ничего.
3. Другому ученику задать комиссию `2500 ₽` без проведённых уроков:
   у трёх ближайших запланированных уроков по `1000 ₽` — прогнозные
   пометки `(~1 000 ₽)`, `(~1 000 ₽)`, `(~500 ₽)`: пунктирная рамка,
   контурный значок, курсив. Показатель списаний в статистике при
   этом `0 ₽`.
4. Отменить ближайший урок с прогнозной пометкой → его пометка исчезла,
   доля перешла следующему по времени.
5. Бесплатный урок (`0 ₽`) — без пометки и остаток не уменьшает.
6. Увеличить комиссию → зачёт продлился дальше; уменьшить ниже уже
   зачтённой → лишние пометки исчезли, сумма пометок равна новой комиссии.
7. Проверить окно просмотра урока — та же пометка в развёрнутом виде.
8. Ширина 375px — пометка со значком не ломает карточку.

### US3 — списания в статистике

1. Отчёты → период «текущий месяц»: карточка «Списано в счёт комиссий»
   равна сумме фактических зачётов.
2. «Заработок» и налог совпадают со значениями до фичи.
3. Сменить период → показатель пересчитался.
4. Ключевая проверка FR-010: урок проведён в марте, оплата отмечена
   в апреле → в статистике за март он в «Заработке», а списание
   в счёт комиссии видно в **апреле**.
5. Репетитор без единой комиссии: ни одного показателя про комиссии
   на странице, но группа «Не зависит от выбранного периода»
   на месте — с «Предоплатой» внутри.

### US4 — прогресс погашения

1. Ученику с комиссией `3000 ₽` отметить оплаченными уроки на `1200 ₽`
   → в карточке: комиссия `3000 ₽`, погашено `1200 ₽`, осталось `1800 ₽`.
2. Полностью погашенная комиссия → тихая строка
   «Комиссия 1 500 ₽ — выплачена», без акцентного блока.
3. Отчёты → в период-независимой группе «Осталось погасить комиссий»
   равно сумме остатков по активным ученикам; смена периода его
   не меняет.
4. Архивировать ученика с непогашенным остатком → общий остаток
   уменьшился на его остаток, прошлые периоды списаний не изменились.

### FR-015 — кабинет ученика

Выдать ученику приглашение, зайти в кабинет ученика: ни суммы комиссии,
ни пометок на уроках, ни блока прогресса — ничего.

## 5. Проверки перед завершением

```bash
cd backend  && npm run lint && npm run build && npm test
cd frontend && npm run lint && npx tsc --noEmit && npm test && npm run find-cycle
```

Дополнительно, специфично для этой фичи:

```bash
# 1. Ни одного маркера строительных лесов не осталось
grep -rn "TODO(auto-feature)" frontend/src backend/src

# 2. Временной страницы макетов и её маршрута больше нет
ls frontend/src/pages/CommissionMockupPage 2>/dev/null
grep -rn "CommissionMockupPage\|mockups/commission" frontend/src

# 3. Временного ре-экспорта LessonCard из features/lessons больше нет
grep -n "LessonCard" frontend/src/features/lessons/ui/index.ts
```

Все три команды должны не найти ничего (кроме отсутствия файла в п.2).

## 6. Частые грабли этого репозитория

- Frontend-тесты — vitest: `npm run test -- path/to/file.test.ts`
  (не `--testPathPattern`).
- Backend-тесты — jest: `npm test -- --testPathPatterns=path`
  (флаг во множественном числе).
- Backend-интеграционные тесты иногда флейкают под параллельным
  прогоном из-за коллизий faker по уникальным `phone`/`email` —
  перезапустить изолированно или с `--runInBand`.
