# Phase 1 Data Model: Заметки урока в карточке списка

Фича не вводит и не изменяет доменных сущностей и не затрагивает БД/Prisma.
Ниже — только используемые данные и локальное UI-состояние.

## Используемые доменные данные (без изменений)

### Урок (Lesson)

- Поле `notes: string` (опциональное; может быть пустым, состоять из пробелов
  или содержать многострочный текст без ограничения длины). Уже существует в
  модели урока и приходит в список уроков. Фича только отображает его.

## UI-состояние (локальное, не персистится)

### LessonNotes (per-card)

- `expanded: boolean` — развёрнута ли заметка. Дефолт `false`. Независимо для
  каждой карточки (FR-006). Хранится в `useState` внутри компонента.
- `isClamped: boolean` — обрезан ли текст в компактном виде. Вычисляется хуком
  `useIsTextClamped` из измерения DOM (`scrollHeight > clientHeight`), не
  хранится как доменные данные. Пересчитывается при смене текста/ресайзе.
- Производное: `showToggle = expanded || isClamped` — показывать ли контрол
  разворачивания/сворачивания.

## Правила отображения (валидация вывода)

- `hasVisibleNotes(notes)` → блок заметки рендерится только если `notes` после
  `trim()` непуст (FR-001, US1 сценарии 2 и 5). Пробелы/пустые строки → блока
  нет.
- Компактный вид ограничен 2 строками (`NOTES_COLLAPSED_LINES = 2`, FR-002).
- Развёрнутый вид сохраняет переносы строк (`white-space: pre-wrap`, FR-004).
- Длинное слово/ссылка не растягивает вёрстку (`overflow-wrap: anywhere`,
  Edge Cases).
