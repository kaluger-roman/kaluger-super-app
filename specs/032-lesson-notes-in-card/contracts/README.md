# Contracts

Фича frontend-only и презентационная: новых API-эндпоинтов, схем запросов/
ответов и контрактов backend нет. Поле `lesson.notes` уже присутствует в
существующей модели урока и приходит в список уроков без изменений контракта.

## Компонентный контракт (frontend)

### `LessonNotes`

Props:

- `notes: string` — текст заметки (непустой; фильтрация пустых выполняется
  вызывающей стороной через `hasVisibleNotes`).

Поведение:

- Рендерит компактный фрагмент (2 строки) с иконкой заметки.
- Показывает контрол «Развернуть»/«Свернуть» только если текст обрезан или уже
  развёрнут.
- Клик по контролу переключает `expanded` и вызывает `stopPropagation`
  (попап урока не открывается).
- `aria-expanded` и `aria-label` на контроле для доступности.

### `hasVisibleNotes(notes?: string): notes is string`

- Возвращает `true`, если `notes` после `trim()` непуст; иначе `false`.
- Type guard: сужает тип к `string` для безопасной передачи в `LessonNotes`.
