# Feature Specification: Налоговая информация на дашборде статистики

**Feature Branch**: `006-tax-statistics`
**Created**: 2026-02-21
**Status**: Draft
**Input**: Добавить информацию о налогах на дашборд финансовой статистики. Ставка налога настраивается в панели профиля пользователя (по умолчанию 6%). На дашборде статистики отображать сумму налогов рассчитанную на основе доходов и ставки налога.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Отображение налогов на дашборде статистики (Priority: P1)

Репетитор открывает страницу статистики и видит информацию о налогах, рассчитанную
на основе его доходов за выбранный период и персональной ставки налога. Это позволяет
ему планировать налоговые отчисления без использования внешних калькуляторов.

**Why this priority**: Основная ценность фичи — репетитор видит налоговую нагрузку
прямо на дашборде, рядом с данными о доходах. Без этого фича не имеет смысла.

**Independent Test**: Открыть страницу статистики с существующими уроками за период,
убедиться что отображается сумма налога = заработок × ставка налога.

**Acceptance Scenarios**:

1. **Given** у репетитора есть завершённые оплаченные уроки за текущий месяц,
   **When** он открывает страницу статистики, **Then** в секции финансовой
   статистики отображается карточка с суммой налога, рассчитанной как
   заработок × ставка налога
2. **Given** у репетитора нет уроков за выбранный период, **When** он смотрит
   статистику, **Then** сумма налога отображается как 0 ₽
3. **Given** репетитор изменил период в фильтре дат, **When** статистика
   обновляется, **Then** сумма налога пересчитывается для нового периода
4. **Given** ставка налога репетитора установлена в 13%, **When** заработок
   за период составляет 50 000 ₽, **Then** отображаемый налог = 6 500 ₽

---

### User Story 2 - Настройка ставки налога в профиле (Priority: P1)

Репетитор заходит в свой профиль и устанавливает персональную ставку налога.
По умолчанию ставка 6% (УСН «Доходы» — самый распространённый режим для
репетиторов-ИП в России). Репетитор может изменить ставку, например, на 13% (НДФЛ)
или 15% (УСН «Доходы минус расходы»).

**Why this priority**: Без возможности задать ставку налога расчёт на дашборде
будет неточным для репетиторов с другим налоговым режимом. Это необходимое условие
для корректной работы User Story 1.

**Independent Test**: Открыть профиль, изменить ставку налога, сохранить,
убедиться что значение сохранено и отображается на странице профиля.

**Acceptance Scenarios**:

1. **Given** новый пользователь, **When** он открывает профиль, **Then** ставка
   налога отображается как 6% (значение по умолчанию)
2. **Given** репетитор на странице профиля, **When** он нажимает «Редактировать»
   и изменяет ставку налога на 13%, **Then** новое значение сохраняется
3. **Given** репетитор вводит ставку налога 0%, **When** он сохраняет,
   **Then** значение 0% принимается (самозанятые без налога на часть дохода)
4. **Given** репетитор вводит значение больше 100% или отрицательное,
   **When** пытается сохранить, **Then** отображается ошибка валидации
5. **Given** репетитор изменил ставку налога в профиле, **When** он переходит
   на страницу статистики, **Then** налоги рассчитаны с новой ставкой

---

### Edge Cases

- Ставка налога = 0% — налог отображается как 0 ₽, карточка всё равно видна
- Ставка налога = 100% — допустимое значение, налог = весь заработок
- У пользователя нет сохранённой ставки (миграция) — используется дефолт 6%
- Заработок за период = 0 — налог = 0 ₽ независимо от ставки
- Дробные значения ставки (например, 6.5%) — допускаются, результат округляется до целых рублей
- Очень большой заработок — сумма налога корректно форматируется с разделителями

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Система MUST хранить персональную ставку налога для каждого пользователя
- **FR-002**: Ставка налога по умолчанию MUST быть 6% для новых пользователей
  и для существующих пользователей без сохранённой ставки
- **FR-003**: Пользователь MUST иметь возможность изменить ставку налога
  на странице профиля
- **FR-004**: Ставка налога MUST принимать значения от 0 до 100 включительно,
  с точностью до одного десятичного знака
- **FR-005**: На странице статистики система MUST отображать карточку с суммой
  налога, рассчитанной как: заработок за период × ставка налога / 100
- **FR-006**: Сумма налога MUST пересчитываться при изменении периода в фильтре дат
- **FR-007**: Сумма налога MUST округляться до целых рублей
- **FR-008**: Расчёт налога MUST выполняться на сервере и возвращаться
  в ответе эндпоинта статистики вместе с остальными финансовыми показателями
- **FR-009**: Расчёт налога MUST использовать только заработок (завершённые
  оплаченные уроки), не потенциальный доход и не задолженности
- **FR-010**: Редактирование ставки налога MUST быть частью существующего
  механизма редактирования профиля (кнопка «Редактировать» / «Сохранить»)

### Key Entities

- **User**: добавляется атрибут «ставка налога» (число с плавающей точкой,
  по умолчанию 6.0, диапазон 0–100)

### Assumptions

- Налог рассчитывается на сервере и возвращается в ответе эндпоинта статистики
  вместе с остальными финансовыми показателями
- Ставка налога — единое значение для всех типов уроков и предметов
- Формула расчёта: округление(заработок × ставка / 100) — простое умножение
  без прогрессивной шкалы или вычетов
- Карточка налога добавляется в существующую секцию финансовой статистики
  на странице отчётов

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Репетитор может установить ставку налога в профиле за 1 действие
  (переключение в режим редактирования, ввод значения, сохранение)
- **SC-002**: Сумма налога на дашборде корректно соответствует формуле
  заработок × ставка / 100 для любого периода
- **SC-003**: Существующие пользователи без сохранённой ставки видят корректный
  расчёт с дефолтным значением 6% без дополнительных действий
- **SC-004**: Изменение ставки в профиле немедленно отражается на странице
  статистики при следующем посещении
