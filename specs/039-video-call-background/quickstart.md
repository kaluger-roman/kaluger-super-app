# Quickstart: 039 — видеозвонок переживает сворачивание

## Подготовка ветки

1. Схема Prisma меняется, поэтому в worktree нужен свой `backend/node_modules`: `cd backend && npm ci` (не симлинк из main — `prisma generate` через симлинк перепишет клиент main checkout). `frontend/node_modules` можно симлинком.
2. `backend/.env` и `backend/.env.test` скопировать из main checkout.
3. `npm run db:migrate` (dev) и `npm run db:migrate:test`.
4. Push локально: `npx web-push generate-vapid-keys` → `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT=mailto:…` в `backend/.env`. Без ключей уведомления скрыты, остальное работает (FR-025) — это тоже нужно проверить.

## Проверки

```bash
npm run check            # из корня: tsc, eslint, prettier, связанные тесты
npm run check -- --full  # перед коммитом
scripts/dev-stack.sh test-backend   # backend jest на ветке
cd frontend && npm run test:e2e -- e2e/students/video-call-background.spec.ts
```

E2E-бэкенд: `NODE_ENV=test`, `E2E=1`, тестовая БД; для сценария с push — VAPID-ключи в env e2e (тестовая пара, не прод).

## Ручная проверка на устройствах (SC-001…SC-005, отчёт manual QA)

Нужны: iPhone с iOS 16.4+ (приложение установлено на экран «Домой»), Android с Chrome, компьютер.
