# Quickstart: 038-lesson-call-button

## 1. Окружение

Ветка `038-lesson-call-button`, worktree
`.claude/worktrees/lesson-call-button` на home. Команды — на home
(`ssh home`), правки файлов — через sshfs-путь.

Ветка меняет Prisma-схему, поэтому `backend/node_modules` в worktree должен
быть своим (`npm ci` в `backend/`), а не симлинком на основной чекаут:
`prisma generate` через симлинк перепишет клиент main checkout.
`backend/.env` и `backend/.env.test` скопированы из основного чекаута.

## 2. Миграция

```bash
cd backend
npx prisma migrate dev --name 038_call_record_lesson
npm run db:generate
npm run db:migrate:test
```

Проверка:

```sql
\d call_records   -- колонка "lessonId" text NULL, FK ON DELETE SET NULL, индекс (lessonId, startedAt)
```

## 3. Тесты и проверки

```bash
# из корня worktree
npm run check            # tsc, eslint, prettier, связанные тесты (во время работы)
npm run check -- --full  # один раз перед коммитом
```

Точечно:

```bash
cd backend && npm test -- --testPathPatterns=callSignaling
cd backend && npm test -- --testPathPatterns=callRecord
cd frontend && npm run test -- src/features/videoCall
cd frontend && npm run test -- src/features/studentSchedule
cd frontend && npm run find-cycle
```

Мок-обвязка снесена полностью:

```bash

# → пусто
```

## 4. Ручная проверка (дев-стек ветки)

`scripts/dev-stack.sh up`; репетитор с учениками: «с кабинетом»,
«без кабинета», «с кабинетом в архиве», пробный урок без ученика; ученик
вошёл в кабинет во второй вкладке/браузере.

| # | Шаги | Ожидание |
|---|---|---|
| 1 | Репетитор: Уроки → урок ученика с кабинетом | В окне урока кнопка «Позвонить» во всю ширину над действиями |
| 2 | Урок ученика без кабинета; пробный урок | Кнопки нет |
| 3 | Прошедший урок ученика в архиве | Кнопка есть, звонок проходит |
| 4 | «Позвонить» | «Начать видеозвонок?», аватар, имя строкой ниже, блок «Звонок по уроку»; звонка нет |
| 5 | Отмена / клик вне окна / Esc | Окно урока открыто, звонка нет |
| 6 | Подтвердить (двойной клик) | Окно урока закрыто, один исходящий звонок |
| 7 | Ученик: входящий | В окне входящего блок «Звонок по уроку» (предмет, день, время) |
| 8 | Завершить звонок; открыть урок снова | Блок «Звонки по уроку»: направление, время, исход, длительность |
| 9 | История звонков (обе стороны) | У звонка строка «Урок: …»; звонки из карточки ученика без неё |
| 10 | Карточка ученика → «Видеозвонок» | Подтверждение без блока урока; после подтверждения карточка закрыта, звонок идёт |
| 11 | Карточка ученика в архиве | «Видеозвонок» есть |
| 12 | Кабинет ученика | В шапке нет «Позвонить» |
| 13 | Ученик: карточка урока в расписании | Окно урока (предмет, статус, день, время, длительность, репетитор), «Закрыть» / «Позвонить» |
| 14 | Ученик: «Позвонить» → подтвердить | Звонок репетитору, у репетитора во входящем блок урока |
| 15 | Ученик: окно урока открыто, репетитор удаляет урок | Окно урока закрывается |
| 16 | Открыто подтверждение, приходит входящий | Подтверждение закрывается, виден входящий |
| 17 | Удалить урок со звонками → история | Записи на месте, без строки урока |
| 18 | Всё выше на 375 px | Вёрстка не ломается, кнопки 48 px |
