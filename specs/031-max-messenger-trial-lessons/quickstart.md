# Quickstart: Мессенджер MAX и пробные уроки без ученика

**Plan**: [plan.md](./plan.md) | **Contracts**: [contracts/api.md](./contracts/api.md)

## Подготовка

```bash
# Backend: миграция + клиент
cd backend
npm run db:migrate        # создаст <ts>_max_and_prospect_lessons
npm run db:generate

# Тестовая БД
npm run db:migrate:test
```

## Проверка фичи руками

### MAX в мессенджерах

1. `cd frontend && npm start`, `cd backend && npm run dev`
2. Ученики → «Добавить ученика» → в «Способ связи» должны быть
   WhatsApp / Telegram / MAX (у ученика и родителя).
3. Выбрать MAX, сохранить → карточка ученика и окно просмотра показывают
   «MAX»; поле «ник» не появляется (только для Telegram).

### Пробный урок без ученика

1. Уроки → «Создать урок» → включить «Пробный урок без ученика».
2. Выбор ученика заменяется полем «Имя ученика» + опциональные телефон
   и мессенджер; цена = 0; переключатель повторения скрыт.
3. Сохранить без имени → русская ошибка валидации.
4. Сохранить с именем → урок в списке/календаре с именем и пометкой
   «пробный»; список учеников не пополнился.
5. Статистика → счётчик пробных уроков увеличился, доход не изменился.

### Привязка к ученику

1. Создать ученика.
2. Открыть пробный урок → редактировать → выключить «без ученика» →
   выбрать ученика → сохранить.
3. Урок отображается как урок этого ученика; prospect-данные исчезли.

## Тесты

```bash
# Backend (jest, реальная тест-БД)
cd backend && npm test
npm test -- --testPathPatterns=lessons      # точечно

# Frontend (vitest)
cd frontend && npm run test
npm run lint && npm run find-cycle

# E2E (playwright)
cd frontend && npm run test:e2e
```

Ключевые регрессионные проверки:

- `reminderProcessor` не падает на уроке без студента (crash-point
  `lesson.student.name`);
- отмена урока без ученика не запускает перенос оплаты;
- `deleteAllFuture` недоступен/безопасен для урока без ученика;
- статистика по студентам не содержит группу `null`;
- кабинет ученика не видит уроки без `studentId` и prospect-поля;
- `price: 0` не подменяется на `hourlyRate` (существующий регресс-тест).
