# Восстановление production на home

## Решения владельца — 04.11.2026

- Production переносится с потерянного VPS на бывшую dev-машину `home`.
- База восстанавливается из последнего целого offsite-бэкапа.
- Пока приложение доступно только по LAN/Tailscale. Публичные домены подключаются
  отдельным этапом после получения статического внешнего IP.
- Разработка, worktrees и тестовые БД работают на Mac. Доступ к `home` по SSH,
  восстановление и production-настройка явно разрешены для этой миграции.

## Требования

1. Отдельный production-каталог, Docker-проект и постоянное хранилище PostgreSQL 16.
2. Исходные бэкапы и старые dev/QA-данные сохраняются; восстановление не перезаписывает их.
3. PostgreSQL и backend не публикуют порты наружу. Web слушает только loopback,
   текущий LAN-IP и Tailscale-IP. Funnel и публичный DNS не включаются.
4. Секреты создаются/хранятся только на сервере, с правами владельца. JWT-ключи
   отделяются от разработки. Существующая email/admin-конфигурация сохраняется;
   криптографически некорректная VAPID-пара заменяется новой для приватного адреса.
5. Сервисы автоматически поднимаются после перезапуска Docker. Startup backend
   не запускает миграции: они выполняются явно после проверки восстановленной БД.
6. PostgreSQL-клиент backend совместим с сервером для новых автоматических бэкапов.
7. Приватный HTTPS включается через Tailscale Serve после разрешения владельца сети.
   Проверки используют только техническое состояние/агрегаты, без тестовых записей
   в восстановленной production-базе и без отправки тестовых писем/push.

## Приёмка

- Архив проходит `gzip -t`; восстановление завершается без SQL-ошибок.
- Количество users/students/lessons проверено, миграции применены без reset/seed.
- Все три сервиса healthy; web, API и WebSocket доступны через приватный адрес.
- Новый бэкап создаётся, проверен и сохраняется вне исходного recovery-архива.
- Подтверждены изоляция портов, права runtime-файлов и restart policy.
- Описаны адреса, восстановленная точка, ограничения и переход к публичным доменам.
