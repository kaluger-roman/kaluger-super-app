# Макеты: Учёт комиссий по ученикам (033-commission-tracking)

Макеты собраны на реальных компонентах приложения с захардкоженными моками.
Временная страница — `frontend/src/pages/CommissionMockupPage`, маршрут
`/mockups/commission/:section` (удаляется на этапе реализации).

Значок комиссии — `Handshake` из `@mui/icons-material`. Фактический зачёт:
заливка, сплошная рамка, заполненный значок, полужирный шрифт, сумма в скобках
`(1 000 ₽)`. Предварительный (прогноз): без заливки, пунктирная рамка, контурный
значок `HandshakeOutlined`, курсив, тильда перед суммой `(~1 000 ₽)`. Различие
читается без опоры на цвет (FR-020, FR-026).

Полностью выплаченная комиссия не занимает место акцентным блоком: и в карточке
ученика, и в окне просмотра она сворачивается в тихую строку обычным стилем
«Комиссия 1 500 ₽ — выплачена»; в списке учеников эта строка убрана внутрь
«Подробностей». Акцентный блок остаётся только там, где остаток ненулевой.

Показатели-снимки на текущий момент вынесены из сетки показателей за период
в отдельную группу под горизонтальным разделителем: подпись
«Не зависит от выбранного периода» и карточки с общим левым акцентом.
В группе две карточки: «Предоплата» (существующий показатель, перенесён
из сетки за период — он и раньше считался без фильтра дат; оформление и
значение не менялись) и «Осталось погасить комиссий» (только при наличии
учеников с ненулевой комиссией). Группа есть на странице всегда, потому
что «Предоплата» есть всегда.
