# Mockups — 030 WebRTC видеозвонки

Статичные макеты (MUI + styled-components) в финальных FSD-локациях. Все данные захардкожены, каждое место для будущего стора/события/эффекта помечено `// TODO(auto-feature)`. Состояния, недостижимые кликом, управляются query-параметром `?mockState=` / `?phase=` (удаляется в Phase 4). Достижимые тогглы (микрофон/камера/экран) переключаются кликом по реальным кнопкам.

Скриншоты: desktop 1440×900, mobile 375×812.

## Точки входа в звонок (User Story 1)

Кнопка старта звонка размещена в реальных (залогиненных) местах — на скриншотах ниже показан результат её нажатия (экран исходящего вызова), сами surface'ы под guard'ом:

- Репетитор → ученик: кнопка «Видеозвонок» в карточке ученика (`StudentViewDialog`), показывается только для зарегистрированного, не архивного ученика.
- Ученик → репетитор: кнопка «Позвонить» в шапке кабинета ученика (`StudentCabinetLayout`).
- «История звонков» добавлена в оба сайдбара (репетитора и ученика).

## Исходящий вызов (User Story 1)

«Вызываем…» с аватаром-заглушкой, именем собеседника и кнопкой отмены.

- `10-desktop-call-outgoing.png` — экран исходящего вызова, десктоп.
- `10-mobile-call-outgoing.png` — экран исходящего вызова, мобильный.

## Входящий вызов (User Story 1)

Модальное окно с именем звонящего и кнопками «Принять» / «Отклонить».

- `11-desktop-call-incoming.png` — входящий вызов, десктоп.
- `11-mobile-call-incoming.png` — входящий вызов, мобильный.

## Активный звонок (User Stories 1, 2, 3)

Большой тайл собеседника + локальный тайл (PiP) + панель управления (микрофон, камера, демонстрация экрана, завершить).

- `01-desktop-call-active-video-on.png` / `01-mobile-...` — видео включено у обоих.
- `02-desktop-call-active-camera-off.png` / `02-mobile-...` — своя камера выключена (аватар-заглушка + индикатор на панели).
- `03-desktop-call-active-mic-muted.png` / `03-mobile-...` — свой микрофон выключен (красный бейдж на тайле + красная кнопка).
- `04-desktop-call-active-peer-camera-off.png` / `04-mobile-...` — у собеседника выключена камера (заглушка «Камера выключена» в большом тайле).
- `05-desktop-call-active-peer-muted.png` / `05-mobile-...` — у собеседника выключен микрофон (бейдж на большом тайле).
- `06-desktop-call-active-screen-sharing.png` / `06-mobile-...` — идёт демонстрация экрана (мок окна + плашка «Демонстрация экрана» + зелёная кнопка).
- `07-desktop-call-active-audio-only.png` / `07-mobile-...` — режим «только аудио» (заглушки с обеих сторон, «Камера недоступна»).
- `08-desktop-call-active-reconnecting.png` / `08-mobile-...` — переподключение (оранжевый баннер «Соединение нестабильно…»).
- `09-desktop-call-active-failed.png` / `09-mobile-...` — не удалось соединиться (красный баннер с дружелюбным сообщением: проверить интернет и позвонить снова).

## История звонков (User Story 4)

Хронологический список (сначала новые): собеседник, направление (вход/исход), дата/время, длительность, статус (завершён / пропущен / отклонён / отменён / не удалось соединиться) + пустое состояние.

- `12-desktop-call-history.png` / `12-mobile-...` — список со всеми типами статусов и направлений.
- `13-desktop-call-history-empty.png` / `13-mobile-...` — пустое состояние «Звонков пока нет».

## Маршруты (мокап)

- `/call?phase=outgoing|incoming|active` + `&mockState=video-on|camera-off|mic-muted|peer-camera-off|peer-muted|screen-sharing|audio-only|reconnecting|failed`
- `/call/history` (+ `?empty=1` для пустого состояния)

Оба маршрута в мокапе отрисованы без guard'ов (помечено TODO) для съёмки без бэкенда и логина.
