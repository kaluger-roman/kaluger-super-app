# Mockups: Заметки урока в карточке списка (032-lesson-notes-in-card)

Скриншоты сняты с реальных компонентов `LessonCard` + нового `LessonNotes`,
отрендеренных через настоящий `LessonsDay` на временном mockup-роуте
(удалён после съёмки). Данные — захардкоженные mock-уроки, покрывающие все
состояния из spec.md.

Карточки в списке (сверху вниз): без заметки, короткая заметка, длинная
заметка (свёрнута), длинная заметка-ссылка без пробелов.

## Реализация

- Новый под-компонент: `frontend/src/features/lessons/ui/LessonsList/components/LessonNotes/`
  (`LessonNotes.tsx`, `.styled.ts`, `.hooks.ts`, `.helpers.ts`, `.constants.ts`, `index.ts`).
- Интеграция: `LessonCard.tsx` рендерит `<LessonNotes />` внутри `ContentColumn`
  только при `hasVisibleNotes(lesson.notes)` (trim → пустая/пробельная заметка не показывается).
- Свёрнутый вид: CSS `-webkit-line-clamp: 2`. Кнопка разворачивания показывается
  только если текст реально обрезан (detection через `scrollHeight > clientHeight`
  + `ResizeObserver` в `useIsTextClamped`).
- Состояние развёрнутости — локальный `useState` в каждой карточке (независимо,
  по умолчанию свёрнуто, не сохраняется между визитами). Это финальный дизайн,
  Effector-стор не требуется (чисто визуальное состояние, не влияет на API/бизнес-логику).
- `LessonsDay` и `WeeklyView` используют один и тот же `LessonCard`, поэтому
  заметки работают одинаково в группировке по датам и в недельном виде (FR-009).
