# Панель Super App

Для панели в текущем чате вызови `super_app_panel`; глобальный пункт «Агенты Super App» доступен в навигации Codex.
`super_app_state` обновляет список, `super_app_session` читает ленту выбранной сессии.

Панель читает открытые issues через локальный авторизованный `gh`; она не меняет GitHub.
Приоритеты и текст «Почему» соответствуют рубрике проекта. Issues без оценки доступны отдельным фильтром.
Для новой работы пользователь выбирает issue и workflow: обычная задача, `$auto-bug-fix --new` или `$auto-feature --new`.
Кнопка открывает новый редактируемый черновик; пользователь отправляет его, чтобы начать работу.
`super_app_prepare_issue` только готовит запрос и не даёт разрешения запускать его автоматически.

Живые статусы относятся к общему CLI daemon. Codex Desktop использует отдельный сервер;
его чаты здесь представлены сохранённой историей, без достоверного живого статуса.
Не выдавай сохранённую историю за работающую сессию и не отвечай за неё на approval/question RPC.

Следуй AGENTS.md выбранного checkout. Локальный плагин не разрешает подключение к старым серверам,
использование production data, автоматический запуск задач, публикацию, сообщения другим людям или изменение issues.
